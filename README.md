## 🎨 Overview

**VibeDraw** is an ultra-fast, market-ready virtual hand-drawn whiteboard and system architecture canvas. Built for rapid ideation, system design sessions, user-flow wireframing, and vibe-coding architecture diagrams, VibeDraw pairs procedural sketch aesthetics with client-side end-to-end encrypted real-time collaboration.

Engineered with an offline-first PWA architecture and local IndexedDB persistence, your drawings are saved immediately in your browser with zero latency and zero data leakage.

---

## ✨ Features

- ✍️ **Hand-Drawn Aesthetic**: Procedural sketch engine powered by [Rough.js](https://roughjs.com/) with customizable stroke width, roughness, fill hatching, and sloppy lines.
- 🔒 **End-to-End Encryption**: Collaborative multi-user canvas rooms encrypted client-side; no diagram data is ever exposed in plaintext.
- 📡 **Offline-First PWA**: Runs anywhere—even without an internet connection—using local browser persistence and service workers.
- 🔄 **Dynamic Arrow & Shape Snapping**: Smart arrows automatically track, bind, and route between diagram blocks and containers.
- 🖼️ **Multi-Format Vector Export**: Export high-fidelity diagrams to vector SVG, high-DPI PNG, or native `.excalidraw` / `.json` files.
- 🌍 **Internationalization (i18n)**: Native multilingual support across 40+ global languages.
- 📐 **Architecture & Icon Libraries**: Modular component libraries for system architecture (AWS, GCP, Kubernetes, UI components).
- 🌓 **Themes & Zen Mode**: Seamless light mode, dark mode, and distraction-free Zen mode for deep focus.

## 🚀 Quickstart

Run VibeDraw locally in 3 steps:

### 1. Clone the repository
```bash
git clone https://github.com/aeskafi/vibedraw.git
cd vibedraw
```

### 2. Install dependencies
```bash
yarn install
```

### 3. Launch development server
```bash
yarn start
```
The application will open automatically at [http://localhost:3000](http://localhost:3000).
